# AWS Certified Solutions Architect – Associate (SAA-C03)

This training is useful for the **data architecture** slice of SAA-C03. It shows when to combine S3, Redshift, streaming, and governed access. SAA-C03 is much broader, so treat this as a focused supplement rather than a primary exam course.

**Fit:** 3/5. **Estimated exam scope introduced:** 10–20%. [AWS's SAA-C03 guide](https://docs.aws.amazon.com/aws-certification/latest/solutions-architect-associate-03/solutions-architect-associate-03.html) weights secure architecture 30%, resilient architecture 26%, high-performing architecture 24%, and cost-optimized architecture 20%. The session overlaps parts of secure data access and high-performing storage/database/ingestion, but barely covers VPC design, compute scaling, high availability, disaster recovery, and cost architecture.
