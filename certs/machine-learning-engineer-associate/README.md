# AWS Certified Machine Learning Engineer – Associate

The session's fraud-scoring example is a useful **ML data and inference** case. Its RAG example connects to the updated beta, but the session is a data-platform course, not an ML engineering course. In particular, **SageMaker Lakehouse/Catalog is not the same subject as SageMaker AI model development**.

**Fit:** 2/5. **Estimated exam scope introduced:** 15–20%. It introduces feature data preparation and real-time scoring, with a little RAG. Model selection, training, tuning, evaluation, MLOps, deployment choices, monitoring, and responsible AI require dedicated study.

**Version as of 2026-09-24:** [AWS's certification page](https://aws.amazon.com/certification/certified-machine-learning-engineer-associate/) lists **MLA-C01** as the current standard exam (English through 2026-09-28) and **MLA-C02 / ME1-C02** as an updated beta with broader GenAI/agentic content; beta delivery begins 2026-09-29. Recheck the page before booking. The course-matched practice here is mostly common to both versions; the RAG item is marked C02-oriented.
