# AWS-authored DEA-C01 practice

1. Open the [official DEA-C01 certification page](https://aws.amazon.com/certification/certified-data-engineer-associate/). Under **Prepare for the exam → Get to know the exam with exam-style questions**, launch the **AWS Certification Official Practice Question Set**. AWS's [exam-prep page](https://aws.amazon.com/certification/certification-prep/) describes its free 20-question sets and the subscription full-length Official Practice Exam.
2. Use the [current exam guide](https://docs.aws.amazon.com/aws-certification/latest/data-engineer-associate-01/data-engineer-associate-01.html) to classify missed items by domain.
3. For questions on streaming, cataloging, Iceberg, Redshift, or Lake Formation, revisit the matching row in [training-extract.md](training-extract.md). For orchestration, monitoring, quality, or IAM/KMS, use the exam guide and additional AWS training.

The [local original test](practice-test.md) is focused on this course and is not AWS-authored. AWS's official practice content is linked rather than copied into this repository so the question set and feedback remain current in Skill Builder.
