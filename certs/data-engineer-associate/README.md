# AWS Certified Data Engineer – Associate (DEA-C01)

This is the best fit for the session: NovaBanco builds the same kind of ingest → catalog → transform → govern → query pipeline that a data engineer must reason about. Use the course extracts first, then test service-selection and operational decisions.

**Fit:** 5/5. **Estimated exam scope introduced:** 40–50%. The course is strongest in ingestion, storage, and governance. It has less on automated orchestration, monitoring, data quality, failure recovery, and cost/performance tuning.

## Study path

1. [Training extract](training-extract.md) — read the linked slides and demo steps in order.
2. [Cheat sheet](cheat-sheet.md) — rehearse why each service is used.
3. [Flashcards](flashcards.md) — recall the choices without looking.
4. [Original practice test](practice-test.md) — answer scenarios, then read the explanations.
5. [Official AWS practice](official-practice.md) — check your understanding against AWS-authored questions.

Exam scope: [AWS DEA-C01 guide](https://docs.aws.amazon.com/aws-certification/latest/data-engineer-associate-01/data-engineer-associate-01.html). Its scored domains are ingestion/transformation 34%, data stores 26%, operations/support 22%, and security/governance 18%.
