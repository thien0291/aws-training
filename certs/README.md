# Certifications matched to this training

The **Modern Data Platform for Banking & Financial Services** session is strongest preparation for AWS data engineering. This guide turns its slides and demos into certification-focused review without treating a one-day session as a full exam course.

For example, the Lake Formation exercise directly supports a Data Engineer security question. It gives some context for a Solutions Architect data-access question, but it does not teach the VPC, multi-AZ, and cost decisions that dominate other SAA-C03 questions.

**How to read the numbers:** Fit is a subjective 1–5 recommendation for using *this particular session* as a starting point. The scope range is an approximate share of exam objectives that the session introduces, based on the current AWS exam guides and the actual slides/demos; it is not a pass probability or a score AWS publishes. “Introduced” includes conceptual mentions, so exam-ready mastery is lower. ## What each folder contains

- `training-extract.md`: selected course sections, with direct links to the archived slide or demo and a short takeaway for that exam.
- `cheat-sheet.md`: decision rules for the overlapping topics, plus exam gaps.
- `flashcards.md`: active-recall questions and answers grounded in the selected material.
- `practice-test.md`: original scenario questions with answer explanations and training links. These are **not AWS-authored exam questions**.
- `official-practice.md`: AWS-authored sample/practice resources. The SAA folder also includes AWS's public SAA-C03 sample-question PDF.

AWS does not publish live exam questions for reuse. Its [official practice question sets](https://aws.amazon.com/certification/certification-prep/) are the closest AWS-authored tests, including free 20-question sets; full official practice exams are available through AWS Skill Builder subscription. The live exam and these study materials have different purposes, so use the official set near the end of preparation.
